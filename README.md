# INNOVATECHSPOR Website

Official responsive landing page for INNOVATECHSPOR — Sports & Fitness.

## Quick start

Open `index.html` in your browser. No build step required. The Google Fonts import needs an internet connection; local fallback fonts are provided.

## Files

- `index.html` — page content and layout
- `styles.css` — brand styles and responsive design
- `script.js` — mobile menu and copyright year
- `assets/innovatechspor-logo.png` — brand logo

## Brand

- Midnight Black: `#101820`
- Neon Green: `#A3E635`
- White: `#FFFFFF`

## Before launch

Update the GitHub URL if the official account differs. Add verified business contact details, product images, inventory and shopping functionality when available. This site is a brand landing page, not a live e-commerce store.
